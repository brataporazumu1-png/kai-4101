# КАИ Пары — группа 4101

Адаптивное веб-приложение расписания для iPhone и компьютера. Содержит занятия с 29 октября 2026 года по декабрь, календарь недель, типы занятий, аудитории и преподавателей, экспорт в .ics, PWA/офлайн-кеширование.

## Опубликовать на GitHub Pages

1. Создайте публичный репозиторий, например `kai-4101`.
2. Загрузите **содержимое этой папки** (файлы `index.html`, `schedule.json`, `sw.js`, `manifest.webmanifest`, `icon.svg`) в корень репозитория.
3. В GitHub откройте **Settings → Pages → Build and deployment** и выберите **Deploy from a branch**, ветку **main**, папку **/(root)**. Нажмите **Save**.
4. После публикации ссылка будет иметь вид `https://ВАШ-ЛОГИН.github.io/kai-4101/` (если репозиторий называется `kai-4101`).
5. На iPhone откройте ссылку в Safari → **Поделиться → На экран «Домой»**.

`build.py` нужен только для пересборки данных и при публикации необязателен.

**Важно:** учебные данные перенесены с присланных скриншотов. Занятия с пометкой ДОТ исключены. Физкультура показывается без номера кабинета. Четверг: 29.10 — программирование, 05.11 — информатика; далее чередуются по конкретным датам в `schedule.json`. Продолжительность пары в приложении принята за 90 минут. При необходимости даты редактируются в `schedule.json`.
